# 🎧 TuneMatch — Song Recommendation Web App

A React-based music recommendation app that suggests songs based on user preferences like genre and mood.

## Features
- Filter songs by **Genre** (Pop, Hip-Hop, Indie, R&B, Pop-Rock)
- Filter songs by **Mood** (Happy, Sad, Energetic, Chill)
- **Search** by artist or song name
- Like/save your favourite songs
- Animated play button UI
- Fully responsive design

## Tech Stack
- **React.js** (Hooks: useState)
- **CSS-in-JS** (inline styles)
- Mock data (can be replaced with Spotify API)

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Monisha-Singhal/tune.git
cd tunematch

# Install dependencies
npm install

# Start the development server
npm start
```
